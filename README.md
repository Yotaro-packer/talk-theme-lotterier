# 説明
投稿されたトークテーマから抽選して「今日のトークテーマ」を表示するアプリのプロトタイプ。
Claude codeを使用する練習として作成。

# 使用したプロンプト
```
以下のアイデアに対するプロトタイプとして最小限の機能を備えたアプリを作る。
**企業内の共有スペースで、初対面の別部署の人と話すきっかけづくりとしてトークテーマをモニターに表示させる。**
社員は各自の端末からトークテーマ投稿用フォームにトークテーマを投稿する。
モニターに表示する画面には「今日のトークテーマ」を大きく表示し、その下に「今後のトークテーマ」(今後1週間の営業日に表示されるトークテーマ)を小さく表示する。
モニターの縦横比は16:9を想定し、ウィンドウサイズの拡大縮小でレイアウトが変わらないようにする。また、レイアウトがスクロール不要で画面内に収まるようにする。
営業日は毎週月～金とし、「今後のトークテーマ」には5営業日分表示する。例として、今日が水曜日の場合は「今後のトークテーマ」に「木、金、月、火、水」のトークテーマ予告が表示される。
営業日終了時、「今日のトークテーマ」を次回のものに切り替えると同時に「今後のトークテーマ」の最後にトークテーマを追加する。追加するトークテーマは投稿された未抽選トークテーマから抽選する。もし未抽選トークテーマが残っていない場合は"トークテーマ応募中！"と表示する。
立ち上げたサーバーは`^C`または`npm stop`で止められるようにする。
今回はプロトタイプのため、以下の通りに実装する。
実際に現在時刻の認識は行わず、代わりに「営業日終了」ボタンを用意し、それをクリックすることで営業日が終了したものとする。
「今日のトークテーマ」及び「今後のトークテーマ」には仮データを初期値として埋める。
モニター表示用画面及びトークテーマ投稿用フォームはローカルマシン上のみで動作させる。
投稿したトークテーマは変数のみで管理し、アプリ終了時に消滅する。
```
上記でプランモードで生成した後、「今後のトークテーマ」内に空欄がある場合、抽選テーブルではなく「今後のトークテーマ」に直接追加するように変更
